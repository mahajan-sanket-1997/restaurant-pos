# Restaurant POS\n\nResponsive multi-device restaurant POS prototype built with Next.js, TypeScript, Supabase and Vercel.\n\n## Current status\n- Interactive floor/table overview with 12 sample tables\n- Sample menu with search and category filters\n- Add/remove quantities on table orders\n- Kitchen display prototype\n- Bill preview and demo-only checkout\n- Sales overview sample\n- Initial Supabase schema deployed to the `restaurant-pos` project, with row-level security policies\n- Vercel project created and configured with public Supabase URL and publishable key\n\n**Important:** the UI is currently a prototype using in-memory sample data. It is not yet connected to Supabase, and demo checkout does not process a real payment. Do not use for live sales yet.\n\n## Run locally\n```bash\nnpm install\nnpm run dev\n```\nCopy `.env.example` to `.env.local` and add your Supabase project URL and publishable/anon key. Never expose a Supabase service-role key in browser code.\n\n## Database\nThe initial schema is stored in `supabase/migrations/20261018000000_initial_restaurant_pos_schema.sql`. It includes restaurants, staff profiles, tables, menu, orders, order items, payments, tenant-scoped RLS policies and realtime publication for tables/orders/order items.\n\n## Next implementation milestones\n1. Authentication and secure owner bootstrap.\n2. Connect tables/menu/orders to the database and Realtime.\n3. Implement transactional bill/payment flow and audit logging.\n4. Add expenses, attendance, payroll and reports.\n5. Verify role permissions, concurrency and backups before production use.\n
